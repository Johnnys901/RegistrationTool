# RegistrationTool
Auto Clicker for "Register Now" Button
A simple, lightweight browser-based auto clicker script designed to automatically click buttons with the "Register Now" text at randomized intervals, featuring work/rest cycles for safe and natural automation.
Features
Automatically detects and clicks all buttons labeled Register Now on the page
Randomized click intervals (1800ms - 2200ms) to simulate human-like behavior
15-minute continuous working cycle followed by a random rest period (5-10 minutes)
Easy start/stop controls and lightweight performance
Pure vanilla JavaScript, no external dependencies
How It Works
The script scans the page for buttons with the exact text Register Now
Clicks the target button at random short intervals
Runs for 15 minutes, then pauses for a random 5–10 minute break
Automatically restarts the cycle after resting
Includes safe stop functions to end all timers and clicks
Usage
Open your browser’s developer console (F12 or Ctrl+Shift+I)
Paste the full script into the console and press Enter
The auto-clicker will start automatically
Run stopScript() in the console to stop all actions at any time
Notes
This script is intended for personal, legitimate use only. Please comply with all website terms of service and avoid unauthorized automation on platforms that prohibit automated clicking.
